# Работа с Git: VS Code и терминал

## Что удобно в VS Code

1. Просматривать diff: добавленные и удалённые строки выделены цветом.
2. Добавлять файлы в индекс и создавать коммит через Source Control.
3. Смотреть автора и историю изменений строк с помощью GitLens.

## Что удобнее в терминале

Выполнять последовательность команд и получать компактный граф истории:
git log --oneline --all --graph.
