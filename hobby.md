# Мой пет-проект

Идея: Telegram-бот для учёта учебных заданий и напоминаний о дедлайнах.

Стек: Python, aiogram, SQLite, Docker.

Цель: научиться создавать Telegram-ботов, хранить данные в базе
и запускать приложение в Docker-контейнере.

## Основные возможности

- Добавление задания с названием предмета и сроком сдачи.
- Просмотр списка невыполненных заданий.
- Напоминание за сутки до дедлайна.

## Этапы реализации

1. Первая версия: добавление заданий, просмотр списка и отметка о выполнении.
2. Вторая версия: напоминания за сутки до дедлайна.
3. Третья версия: упаковка приложения в Docker и автоматический запуск тестов.

## Разделение данных пользователей

Каждое задание в SQLite связано с Telegram user ID владельца.
При просмотре, изменении и удалении задания бот проверяет этот ID,
чтобы пользователь мог работать только со своими заданиями.
